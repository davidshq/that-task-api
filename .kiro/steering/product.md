# Product Overview

That Task API is a backend-first task and project management system designed to serve as a solid foundation for custom task management applications.

## Core Philosophy
- API/backend first approach - no UI assumptions
- Flexible foundation for others to build upon
- Avoid adding to the "bazillion" existing task apps by focusing on the backend
- Support for unique functionality often missing from existing solutions

## Key Features
- Hierarchical task organization with subtasks
- Custom fields and extensible data model
- Recurring tasks and notifications
- Non-member interactions (external stakeholders)
- Gamification support
- Comprehensive audit logging

## Target Use Cases
- Foundation for custom task management UIs
- Support for various interaction paradigms (CLI, web, mobile, etc.)
- Integration with external systems and workflows
- Neurodivergent-friendly task management
- Complex project hierarchies and dependencies
